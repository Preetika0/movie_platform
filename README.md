# Movie Platform

A web-based Movie Platform that allows users to explore, search, and interact with movie content. This project focuses on providing a simple and user-friendly interface for discovering movies and their details.

## Features
 * Search for movies
 * View movie details
 * User-friendly interface
 * Responsive design
 * Organized project structure
## Tech Stack
* Frontend: HTML, CSS, JavaScript
* Backend:  Node.js
* Database: MongoDB
## Usage
* Open the application
* Search for a movie
* Browse details and explore
